## Contract and the natural-language correction

Python supplies questions and local menus, validates proposals, captures decisions and compiles.

of the prompt**, not just its printed layout. Natural-language action, movement, performance,
camera and causal descriptions must embody the same considered decisions as structured controls.
Do not produce a generic prose summary while reserving meaningful direction for YAML/XML/JSON.

that keeps its release readable. The accepted description carries that pathway and its resulting
action, rather than only naming "a dramatic spell." Capture concise application reasons, and
include WHY or camera motivation where the selected layout needs them. This is visible directing
output, not private chain-of-thought or an instruction for the video model to run our reasoning.

score. NL, YAML, XML, JSON and requested hybrids remain authoring and provider-projection choices.

wrapper may invent a replacement scene. Preserve user locks and report unsupported requests.

Determinism begins with captured interpretation, choices, source/configuration versions and build
settings. Fresh LLM judgment can vary. Accepted-state replay must retain artifact identity.

## Shared decision loop

visible description and concise reason → deterministic checks → accepted state → dependent needs
and projection. Accepted revisions reopen affected coverage and review through the current owner.

A need names an existing pass/sublayer, action/shot/scene target, relevant knowledge and resolution.
Derive it from the current accepted state and captured policy. Relevant required needs must resolve;
optional non-applicability needs a reason. Missing research is not automatically non-applicability.

code does not become valid through that label. Explicit user facts retain their spans; only actual
protected choices are locks. Never-ask delegates artistry, not necessary exact assets or credentials.
